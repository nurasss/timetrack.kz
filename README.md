# ⏱️ timetrack.kz — Система учета рабочего времени и биометрии (Полный архив)

Полный инженерный и аварийный архив программного комплекса **timetrack.kz**: SaaS-платформы контроля рабочего времени сотрудников, биометрической верификации лиц (Face ID), учета смен, гео-локации и расчета табелей заработной платы.

---

## 📌 Архитектура архива и состав компонентов

В архив включены исходные коды, базы данных и серверные конфигурации с виртуального хостинга (`195.210.46.53`) и выделенного VPS сервера (`194.238.42.177`):

```text
timetrack.kz/
├── vps/                                    # Данные с выделенного VPS-сервера
│   ├── opt-timetrack/timetrack/            # Исходные коды компонентов
│   │   ├── timetrack-web/                  # React/Node.js панель администратора компании
│   │   ├── timetrack-mobile/               # Мобильное приложение сотрудников (React Native / Expo)
│   │   ├── dev-timetrack/                  # Документация дизайн-системы и API контрактов
│   │   └── apps/mobile/                    # Исходники мобильных клиентов
│   ├── volumes_extracted/                  # Тома Caddy Server (активные SSL сертификаты Let's Encrypt)
│   └── opt_timetrack_full.tar.gz          # Сжатый бэкап рабочей директории VPS
├── hosting/                                # Файлы виртуального хостинга
│   └── timetrack.kz/                       # Промо-сайт, редиректы и лендинги
└── README.md                               # Реестр компонентов
```

## 🛠 Стек технологий

- **Панель управления**: React, TypeScript, Node.js, Tailwind CSS.
- **Мобильное приложение**: React Native, Expo, Face Recognition SDK, Geolocation API.
- **Инфраструктура**: Caddy (Zero-Config HTTPS), Docker, PostgreSQL.
