# Timetrack — қазақша бейне

Казахская версия 20-секундного ролика Timetrack.

Видео: `../brag-kk.mp4` (1920 × 1080, 30 кадров/с).
Исходник композиции: `index.html`.

Проверка: `npm run check`.
Повторная сборка: `npm run render`.

В таблице «Д» означает «демалыс» (выходной).
Первая строка: Аманбаев Олжас. Подписи интерфейса планшета переведены слоями SVG поверх исходного изображения.
